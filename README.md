# GolfScore

ゴルフスコアをプレイ中に少ない手間で入力出来ます
  
* Par設定はAIを活用可能
* 打数、パット数、オリンピック得点
* 打数、パット数、には予測機能付き
* 結果はファイルとして書き出し/読み込み可能
* 過去の結果ファイルを雛形として利用可能

* PWA対応で、通常アプリっぽく使える

## 🚀[Webから実行出来ます！](https://sugarware.github.io/GolfScore)

実行後にブラウザのメニューから「ホーム画面に追加」を選べば、アプリっぽく使えます
その後はブラウザの内部メモリに登録されるので、オフラインでも起動できます
